# Showket Ahamed Portfolio

This is a ready-to-open static portfolio website customized for Showket Ahamed.

## Files

- `index.html` - portfolio content
- `styles.css` - simple colorful responsive design with smooth animations
- `script.js` - mobile menu, scroll progress, reveal animations, active navigation, and email contact form
